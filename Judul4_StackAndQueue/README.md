Membuat Antrian Pengambilan Obat Menggunakan Queue

Program ini berfungsi untuk mengatur urutan pelayanan pasien secara terstruktur dengan prinsip FIFO (First In, First Out), yaitu pasien yang datang 
lebih dahulu akan dilayani lebih dahulu. Tujuan dibuatnya kode ini adalah untuk memastikan proses antrian berjalan dengan tertib, menghindari adanya 
pasien yang saling mendahului, serta mempermudah petugas dalam mengelola dan memanggil pasien sesuai urutan. Selain itu, sistem ini juga membantu 
meningkatkan efisiensi dan keadilan dalam pelayanan, sehingga proses pengambilan obat menjadi lebih rapi, terorganisir, dan nyaman bagi semua pihak.
